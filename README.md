# DSE সুইং স্ক্যানার

ঢাকা স্টক এক্সচেঞ্জের দৈনিক ডেটা থেকে ২–২০ দিনের সুইং ট্রেডের সংকেত খোঁজে। পেজ: `docs/index.html` (GitHub Pages)।

## ২ বছরের ডেটা ভরার নিয়ম (একবারই করতে হবে)

1. GitHub-এ রিপোজিটরির **Actions** ট্যাব খুলুন।
2. বাঁ পাশ থেকে **"DSE ডেটা আপডেট"** workflow বেছে নিন।
3. **Run workflow** চাপুন। `bootstrap` ঘরে `true` লিখুন, `days` ঘরে `760` রাখুন, তারপর **Run workflow**।
4. কাজ শেষ হতে ৩০–৬০ মিনিট লাগতে পারে। এটি আগের ডেটা না মুছে শুধু পুরনো অংশ (প্রথম সংরক্ষিত দিনের আগে) ভরে, আর DSEX ইনডেক্সের ২ বছরের ইতিহাসও নামায়।
5. শেষ হলে স্ক্যানার পেজ রিফ্রেশ করুন। "ডেটা" অংশে `প্রথম তারিখ থেকে শেষ তারিখ (৫০০+ ট্রেডিং-দিন ≈ ২ বছর)` দেখাবে।

এরপর প্রতিদিনের আপডেট নিজে থেকে চলবে। সর্বোচ্চ ৫৬০ ট্রেডিং-দিন (≈ ২ বছর ২ মাস) রাখা হয়, তার পুরনোগুলো নিজে থেকে বাদ যায়।

## হাতে চালাতে চাইলে

```
python scripts/update_data.py --bootstrap --backfill --days 760   # পুরনো অংশ ভরে
python fetch_dsex.py 800                                          # DSEX ২ বছর
python tests/test_update_data.py                                  # টেস্ট
```

## ওভারফিটিং যাচাই

স্ক্যান ফলাফলের নিচে "সময়ভাগ অনুযায়ী যাচাই" ছক আছে। থ্রেশহোল্ডগুলো আগের ১৩ মাসের (২০২৫-০৯-০১ থেকে) ডেটা দেখে বাছা হয়েছিল। নতুন ভরা পুরনো অংশ বাছাইয়ে ব্যবহৃত হয়নি, তাই সেই সারির "আলফা" (র‍্যান্ডম কেনার চেয়ে বেশি রিটার্ন) নিয়মগুলোর আসল পরীক্ষা।
